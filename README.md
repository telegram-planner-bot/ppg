# Бот-планировщик для Telegram

Бот-ассистент для планирования дел: встречи, звонки, задачи. Каждое дело
относится к одной из категорий матрицы Эйзенхауэра, а бот сам присылает
напоминание в Telegram заранее (за столько минут, сколько вы укажете в
настройках — по умолчанию за 60 минут). Напоминание приходит как обычное
сообщение от бота — если в телефоне включены уведомления Telegram, оно
всплывёт как push-уведомление.

Эта инструкция — способ запустить бота **вообще без установки чего-либо
на свой компьютер**. Всё делается через браузер: три бесплатных
веб-сервиса (Telegram, GitHub, Render) и один "будильник" (UptimeRobot),
чтобы бот работал круглосуточно.

Понадобится: браузер, эта папка с файлами бота (уже распакована), и
терпение минут на 20 на первый раз — дальше бот работает сам.

## Шаг 1. Получить токен бота у @BotFather

1. Откройте Telegram, найдите бота **@BotFather** (официальный бот
   Telegram для создания других ботов).
2. Отправьте `/newbot`.
3. Придумайте имя бота (то, что видно в чате) — например, «Мой
   Планировщик».
4. Придумайте username бота — обязательно должен заканчиваться на `bot`
   (например, `petr_planner_bot`).
5. BotFather пришлёт **токен** — строку вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Скопируйте и сохраните его куда-нибудь (заметки) — он понадобится в
   шаге 3. Никому его не показывайте.

## Шаг 2. Загрузить код бота на GitHub (без установки git)

GitHub — это просто место, откуда хостинг возьмёт код бота. Программы
ставить не нужно, всё через сайт.

1. Зайдите на https://github.com и нажмите **Sign up** — создайте
   бесплатный аккаунт (email, пароль, имя пользователя).
2. После входа нажмите **+** в правом верхнем углу → **New repository**.
3. Назовите репозиторий, например `telegram-planner-bot`. Оставьте его
   **Public** (для бесплатного хостинга это ок — токен бота туда не
   попадёт, мы его добавим отдельно, безопасно). Нажмите **Create
   repository**.
4. На странице репозитория нажмите **Add file → Upload files**.
5. Перетащите в окно браузера **все файлы из папки бота** (`bot.py`,
   `db.py`, `requirements.txt`, `render.yaml`, `.env.example`,
   `README.md`) — именно файлы, не саму папку.
6. Внизу нажмите **Commit changes**.

Готово — код бота теперь лежит на GitHub.

## Шаг 3. Развернуть бота на Render (бесплатный хостинг)

1. Зайдите на https://render.com и нажмите **Get Started** — можно
   зарегистрироваться через аккаунт GitHub (проще всего) или email.
   Банковская карта для бесплатного тарифа не требуется.
2. В панели Render нажмите **New +** → **Web Service**.
3. Нажмите **Connect account** рядом с GitHub (если ещё не подключали) и
   разрешите доступ. Выберите репозиторий `telegram-planner-bot`.
4. Заполните поля:
   - **Name**: любое, например `telegram-planner-bot`.
   - **Region**: любой ближайший (например, Frankfurt).
   - **Branch**: `main`.
   - **Runtime**: `Python 3`.
   - **Build Command**: `pip install -r requirements.txt`.
   - **Start Command**: `python bot.py`.
   - **Instance Type**: **Free**.
5. Ниже — раздел **Environment Variables**. Нажмите **Add Environment
   Variable** и добавьте:
   - Key: `BOT_TOKEN`
   - Value: токен, который дал BotFather в шаге 1.
6. Нажмите **Create Web Service**.

Render начнёт сборку — это займёт пару минут. Когда в логах появится
`Бот запущен`, а статус сверху станет **Live**, бот уже работает.
Наверху страницы будет ссылка вида `https://telegram-planner-bot-xxxx.onrender.com`
— скопируйте её, она нужна для следующего шага.

## Шаг 4. Не дать боту "уснуть" (UptimeRobot)

Бесплатный тариф Render "усыпляет" сервис, если к нему никто не
обращался 15 минут. Чтобы бот работал постоянно, настроим бесплатный
внешний "пинг" каждые 5 минут.

1. Зайдите на https://uptimerobot.com и зарегистрируйтесь (бесплатно,
   карта не нужна).
2. Нажмите **Add New Monitor**.
3. Заполните:
   - **Monitor Type**: `HTTP(s)`.
   - **Friendly Name**: например `planner bot`.
   - **URL**: ссылка из Render (шаг 3), например
     `https://telegram-planner-bot-xxxx.onrender.com`.
   - **Monitoring Interval**: 5 минут.
4. Нажмите **Create Monitor**.

Теперь UptimeRobot каждые 5 минут будет "стучаться" в бота, и Render не
будет его усыплять.

## Шаг 5. Проверить, что бот работает

Откройте Telegram, найдите своего бота по username и нажмите **Start**
(или отправьте `/start`). Дальше пользуйтесь кнопками меню.

## Как пользоваться ботом

- **➕ Добавить дело** — бот спросит название, дату/время
  («сегодня 18:00», «завтра 09:30» или «25.12 14:00»), категорию:
  - 🔴 Срочно и важно
  - 🟡 Важно, не срочно
  - 🟠 Срочно, не важно
  - ⚪ Не срочно и не важно

  и в конце — за сколько напомнить об этом деле. Здесь можно выбрать
  **сразу несколько** вариантов (15 мин / 30 мин / 1 ч / 2 ч / 3 ч /
  1 день) — например «1 день» и «3 ч», чтобы напоминание пришло и
  накануне, и незадолго до начала. Выбранные варианты отмечаются ✅,
  когда всё выбрано — нажмите «Готово ✔️».
- **📅 Сегодня** — список дел на сегодня.
- **📋 Все дела** — все незавершённые дела, сгруппированные по категориям.
- **⚙️ Настройки** — значение «по умолчанию», которое будет предложено
  (предварительно отмечено) при создании новых дел — его всегда можно
  дополнить другими вариантами или снять при создании конкретного дела.
- Под каждым делом — кнопки **✅ Выполнено** и **🗑 Удалить**.

## Как обновить бота позже (если что-то поменяем в коде)

1. На странице репозитория на GitHub — **Add file → Upload files** —
   загрузите изменённые файлы ещё раз, **Commit changes**.
2. Render сам заметит изменения в GitHub и пересоберёт бота (обычно
   в течение минуты-двух). Ничего дополнительно нажимать не нужно.

## Если что-то не работает

- В Render на вкладке **Logs** видно, что происходит с ботом — там же
  видны ошибки, если что-то пошло не так.
- «Не найден BOT_TOKEN» — проверьте, что в Render, в разделе
  **Environment**, есть переменная `BOT_TOKEN` с правильным значением
  (без лишних пробелов).
- Бот не отвечает в Telegram — откройте Logs в Render и убедитесь, что
  там есть строка `Бот запущен`, и что статус сервиса — **Live**, а не
  **Suspended**/**Failed**.
- Иногда бесплатный Render всё равно может ненадолго "заснуть" или
  перезапуститься (например, во время планового обслуживания) — в эти
  минуты напоминания могут прийти с задержкой. Для полностью надёжной
  работы 24/7 в будущем можно перейти на платный тариф (от ~$7/мес) —
  скажите, если понадобится, помогу настроить.

## Важное ограничение бесплатного варианта

На бесплатном тарифе Render список дел (файл `planner.db`) хранится на
диске сервиса, но **при каждом обновлении кода** (шаг «Как обновить
бота позже») Render пересобирает сервис заново, и накопленные дела
могут не сохраниться. Пока вы просто пользуетесь ботом, ничего не
трогая в коде — дела сохраняются. Но если в будущем понадобится часто
обновлять код и не терять историю дел, лучше подключить постоянное
хранилище (платный Render Disk, ~$1/мес) или переехать на другой
хостинг — напишите, поможем настроить, когда будет актуально.

## Дальше можно добавить

- Повторяющиеся дела («каждый понедельник», «каждый день»).
- Индивидуальное время напоминания для конкретного дела.
- Более надёжный (платный) хостинг без риска "уснуть".

Просто напишите, что из этого нужно — доработаем.
